# Personal Portfolio Website (Group 1 - Project 1)

A responsive, modern student personal portfolio webpage built strictly using **semantic HTML5 and CSS3** (No JavaScript or external frameworks).

## 🚀 Project Overview
This project fulfills the Creative HTML & CSS Webpage Project requirements for **Group 1 (Project 1)**:
- **Profile / Hero Section**: Student introduction, title, profile avatar, and primary calls-to-action.
- **About Section**: Academic background, core interests, and career objectives.
- **Skills Matrix**: Categorized technical proficiencies, frontend principles, and tools.
- **Projects Section**: Interactive project cards showcasing work samples with tags and category badges.
- **Achievements Section**: Vertical milestone timeline highlighting academic and project recognitions.
- **Contact Section**: Detailed contact channels paired with a clean, responsive input form.

## 🛠️ Built With
- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`).
- **CSS3**:
  - CSS custom properties (variables) for consistent themes.
  - Flexbox and CSS Grid for layout structuring.
  - Pure CSS responsive navigation toggle (checkbox hack).
  - Media queries for cross-device responsiveness (desktop, tablet, mobile).
  - Google Fonts (`Poppins`).
